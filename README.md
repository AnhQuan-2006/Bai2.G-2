2. Cách chạy chương trình

Bước 1: Mở thư mục chứa file server.js bằng Visual Studio Code.

Bước 2: Mở Terminal trong VS Code.

Bước 3: Nhập lệnh:

node server.js

Bước 4: Mở trình duyệt và truy cập:

http://localhost:3000

3. Kết quả thực hiện

Server khởi động thành công tại cổng 3000.

Sử dụng module http của Node.js.
